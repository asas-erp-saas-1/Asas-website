# ASAS Expert CRO / UX Standard

Last updated: 2026-09-12

This is the review gate for every public ASAS page. The objective is a credible, low-friction path from visitor to qualified conversation—not visual novelty for its own sake.

## Conversion sequence

1. Orientation — understand ASAS and the offer immediately.
2. Relevance — find a suitable project or apartment quickly.
3. Desire — real imagery, architecture, location, and concise positioning.
4. Proof — truthful inventory, price, surface, delivery, amenities, plans, map, and project facts.
5. Action — one dominant next step: availability, visit, information, or qualified contact.
6. Human handoff — WhatsApp, phone, and lead form support the decision without competing equally.
7. Recovery — unavailable inventory, missing media, errors, and empty states always offer a useful next action.

## Page gates

### Home
- Proposition + primary action + real project signal above the fold.
- Small number of high-confidence proof points; never fabricate social proof or metrics.
- Route visitors into Projects before asking for unnecessary contact details.

### Projects / Catalog
- Search and filters are immediately understandable.
- Cards expose decision-critical information before the detail page: project, location, status/type, price when available, and key apartment signals.
- Touch-safe controls and explicit reset behavior.
- Map is evidence, not decoration; missing coordinates produce a truthful empty state.
- Empty results provide recovery actions.

### Project Detail
- Hero communicates identity, location, price position, status, and next action.
- Inventory is the commercial core and availability is truthful.
- Evidence follows desire: gallery, essentials, location, amenities, delivery.
- Primary decision card remains visible on desktop while evidence is inspected.
- Core information is visible as sections rather than hidden behind horizontal tabs.

### Apartment Detail
- First viewport answers what it is, where it is, size, price, and next action.
- Real images only; no invented media.
- Facts remain scannable.
- Availability changes CTA language: visit for available inventory; information/conditions for coming-soon or reserved inventory.
- Project context and alternatives prevent dead ends.
- No public bank-credit simulation.

### Services / About / Developers / Contact / Insights
- Each page has one job and one dominant CTA.
- Copy is outcome-led and evidence-based.
- Forms minimize friction and preserve contextual intent.
- Developer pages sell commercial execution and quality, not software features.
- Insights answers real decision questions and routes readers toward a relevant action.

## Universal interaction gates

- Primary controls: minimum 44px touch target.
- Visible keyboard focus.
- No horizontal overflow on mobile.
- Clear loading, empty, and error states.
- No fake urgency, scarcity, testimonials, statistics, or unsupported neighborhood claims.
- No competing mobile sticky layers.
- Editorial real-estate visual language; no dashboard/SaaS clutter on public pages.

## Measurement gates

Track at minimum: catalog search/filter usage; project inventory clicks; apartment primary CTA clicks; WhatsApp/phone clicks; lead-form starts, validation errors and submissions; qualified intent; favorite/compare/share; and recovery from empty/error states.

Do not claim conversion lift without ASAS analytics. CRO iterations follow functional correctness, accessibility, responsive verification, and production health.

## Release rule

A page is finished only when its business journey, truthful data, interaction model, responsive behavior, accessibility, recovery paths, analytics, and production verification are coherent.
