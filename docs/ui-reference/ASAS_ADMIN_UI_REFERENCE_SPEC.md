# ASAS Admin UI Reference Specification

Editable Figma reference: https://www.figma.com/design/G4zoKNzl1FBcN2kxrNikwk

Repository preview: `docs/ui-reference/asas-admin-ui-contact-sheet.svg`.

Screens: Executive Dashboard; Projects; Project Detail; Buildings; Apartments; Apartment Detail; Leads.

UX contract: Site Operations = Project → Building → Apartment → Availability. Customer Operations = Lead → Follow-up → Interest → Negotiation → Reservation boundary. Material actions follow context → preconditions → permission → state → action → validation → mutation → feedback → recovery → audit → next action.

No unsupported Reservation/Contract/Payment execution is visually fabricated.

Visual direction: premium operational console, dark charcoal navigation, forest green primary actions, restrained gold emphasis, warm neutral workspace, dense readable data, explicit state badges, clear action hierarchy, and responsive information hierarchy.
